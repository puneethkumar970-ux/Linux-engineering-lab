# Linux System Health Monitor

## Overview

A Bash script designed to provide a quick overview of the health and status of a Linux system.

## Features

- Displays system information
- Checks CPU usage
- Checks memory usage
- Checks disk usage
- Displays system uptime
- Provides useful system health information

## Technologies Used

- Linux
- Bash
- Linux command-line utilities

## How to Run

Make the script executable:

```bash
chmod +x System_monitor.sh
